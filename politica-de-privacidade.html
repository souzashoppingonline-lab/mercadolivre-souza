1. O que é este Sistema

O Multimix Vendas é um painel operacional interno, usado pela própria empresa vendedora para acompanhar as vendas das suas contas nos marketplaces conectados. Não é um serviço vendido a terceiros nem acessado pelo público em geral — só por funcionários autorizados da empresa.

2. Quais dados são coletados

O Sistema só acessa dados que o próprio vendedor autoriza explicitamente ao conectar sua conta de marketplace via OAuth (Mercado Livre, Amazon, Shopee, TikTok Shop). Isso inclui:

  • Dados de pedidos e vendas: identificador do pedido, valor, status, itens, data, tipo/custo de envio.
  • Dados do comprador quando fornecidos pelo marketplace: apelido/nome do comprador — usado só para exibir no pedido, nunca repassado a terceiros.
  • Dados do catálogo: título, preço, estoque e imagem dos anúncios da própria loja.
  • Tokens de acesso (access/refresh token) emitidos pelo marketplace para o Sistema poder consultar os dados acima em nome do vendedor — armazenados apenas no servidor, nunca expostos ao navegador.

O Sistema não coleta dados de quem não seja usuário autorizado desta página e não usa cookies de rastreamento de terceiros nem pixels de publicidade.

3. Como os dados são usados

  • Exibir vendas, pedidos e indicadores nos dashboards internos.
  • Enviar notificações operacionais (ex.: aviso de nova venda) por Telegram para a própria equipe.
  • Gerar relatórios financeiros e de desempenho para a própria empresa vendedora.

Os dados nunca são usados para publicidade, revenda a terceiros ou qualquer finalidade fora da operação da própria loja.

4. Compartilhamento de dados

O Sistema não vende, aluga nem compartilha dados de pedidos, clientes ou lojas com terceiros. Os dados trafegam apenas entre o marketplace (Mercado Livre/Amazon/Shopee/TikTok Shop) e o servidor do próprio Sistema, hospedado em infraestrutura controlada pelo responsável acima.

5. Armazenamento e segurança

  • Dados ficam em banco de dados próprio (PostgreSQL), com acesso restrito à equipe técnica.
  • Toda comunicação com o Sistema é feita via HTTPS.
  • O acesso ao painel é restrito por login de funcionário (usuário/senha), com papéis de permissão por função.
  • Tokens de acesso dos marketplaces nunca são enviados ao navegador — ficam só no servidor.

6. Retenção dos dados

Os dados são mantidos enquanto a conta do marketplace estiver conectada ao Sistema e pelo prazo necessário para fins fiscais/contábeis exigidos por lei. O vendedor pode solicitar a desconexão da conta e a exclusão dos dados associados a qualquer momento, pelo contato informado acima.

7. Direitos do titular (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei 13.709/2018), qualquer titular de dados tratados pelo Sistema pode solicitar, pelo contato acima: confirmação de tratamento, acesso, correção, anonimização, portabilidade ou eliminação dos seus dados, dentro dos limites legais.

8. Cookies

O Sistema usa apenas um cookie de sessão (httpOnly) para manter o login de funcionários autenticados, e armazenamento local do navegador (localStorage) para preferências de interface (ex.: aba selecionada). Nenhum dos dois é usado para rastreamento entre sites.

9. Alterações desta política

Esta política pode ser atualizada para refletir mudanças no Sistema ou na legislação aplicável. A data no topo desta página indica a última revisão.
