Padrão de Proteção de Dados Pessoais

FinanceEcom — Padrão Interno de Segurança e Proteção de Dados

1. Objetivo

Este documento estabelece os princípios e práticas internas adotados pelo FinanceEcom para proteger dados pessoais e outras informações sensíveis processadas por seus sistemas, serviços, integrações e operações de negócio.

2. Abrangência

Este padrão se aplica a dados pessoais processados pelo FinanceEcom e aos sistemas, aplicações, bancos de dados, APIs, integrações, infraestrutura, funcionários, prestadores e usuários autorizados envolvidos nesse processamento.

3. Princípios de Proteção de Informação

PrincípioPrática interna
Minimização de dadosSó é coletada e processada a informação necessária para finalidades legítimas de negócio e de serviço.
ConfidencialidadeDados pessoais e informação sensível não podem ser divulgados ou disponibilizados a partes não autorizadas.
Controle de acessoAcesso a sistemas, bancos de dados, credenciais, tokens de API e dados pessoais é restrito a pessoal autorizado.
SegurançaMedidas técnicas e administrativas são usadas para reduzir o risco de acesso não autorizado, divulgação ou perda.
Responsabilização (accountability)Atividades relacionadas a segurança e ações administrativas relevantes devem ser documentadas quando aplicável.
RetençãoA informação deve ser retida só pelo tempo razoavelmente necessário para fins operacionais, contratuais ou legais.

4. Gestão de Acesso

O FinanceEcom restringe o acesso a sistemas e informação de acordo com a necessidade de negócio. Onde tecnicamente possível, credenciais individuais são usadas para identificar usuários autorizados. Permissões de acesso devem ser revisadas e ajustadas quando responsabilidades mudam.

5. Credenciais, Tokens de API e Segredos

Senhas, tokens de API, access tokens, refresh tokens, chaves de API e outros segredos de autenticação são tratados como informação confidencial. Devem ser armazenados com segurança e nunca expostos em interfaces públicas, repositórios de código-fonte ou logs de aplicação.

6. Integrações de API e Marketplace

O FinanceEcom usa integrações de API autorizadas para se conectar com plataformas e serviços de terceiros. Só deve ser acessada a informação e a permissão necessárias para a funcionalidade autorizada. Credenciais de autenticação e tokens devem ser protegidos contra divulgação não autorizada.

7. Armazenamento e Transmissão de Dados

Quando aplicável, dados pessoais e informação sensível devem ser protegidos durante a transmissão por meio de mecanismos de comunicação seguros. Informação armazenada deve ser protegida por controles de acesso apropriados e medidas de segurança de infraestrutura.

8. Segurança de Aplicação e Infraestrutura

Considerações de segurança são incorporadas ao desenvolvimento, manutenção e operação dos sistemas do FinanceEcom. Isso inclui atenção a autenticação, autorização, acesso a banco de dados, segurança de API, dependências, configuração de servidor e proteção de informação de configuração sensível.

9. Acesso de Terceiros

O acesso de terceiros à informação deve se limitar ao necessário para serviços autorizados, integrações, operações técnicas ou outras finalidades legítimas de negócio. O acesso deve ser controlado de acordo com as permissões aplicáveis.

10. Gestão de Incidentes de Segurança

Potenciais incidentes de segurança envolvendo dados pessoais ou informação sensível devem ser identificados, registrados e avaliados. Ações apropriadas de contenção, correção e prevenção devem ser tomadas quando necessário.

11. Responsabilidades de Funcionários e Usuários

Usuários autorizados são responsáveis por proteger suas credenciais, seguir os procedimentos de segurança aplicáveis, usar a informação só para finalidades legítimas de negócio, e reportar suspeitas de incidente de segurança ou acesso não autorizado.

12. Revisão Periódica

Este padrão deve ser revisado periodicamente e atualizado quando ocorrerem mudanças significativas em sistemas, integrações, processos de negócio, práticas de segurança ou requisitos aplicáveis.

13. Declaração de Compromisso

O FinanceEcom está comprometido em proteger dados pessoais e manter salvaguardas técnicas e organizacionais razoáveis, desenhadas para preservar a confidencialidade, integridade e segurança da informação processada por seus serviços e integrações.

14. Status do Documento

Este documento descreve o padrão interno de proteção de informação do FinanceEcom. É um documento de segurança interno e não constitui, por si só, uma certificação independente, auditoria externa ou certificação legal de conformidade.
